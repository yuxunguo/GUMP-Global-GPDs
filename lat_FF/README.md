minus_t.npy : the x-axis values in Fig. 1 in units of GeV^2 (34 entries)

AgDg_[mean/cov].npy: the mean and covariance matrix for the gluon data points (67 entries)

AqDq_[mean/cov].npy: the mean and covariance matrix for the singlet flavor quark point (67x67 entries)

Please note that only Ag and Aq are constrained for the first momentum value, t=0 GeV^2, while the D data start at the second momentum value, t=-0.07243 GeV^2. Therefore in the mean files, the first 34 elements correspond to A and the last 33 elements correspond to D. The same order is used for the covariance matrices as well.
